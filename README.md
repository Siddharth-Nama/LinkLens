# LinkLens

Hosted HTTPS API that accepts a LinkedIn profile URL and returns structured JSON for the data visible on that profile.

This project is a take-home engineering challenge. It talks to LinkedIn’s authenticated Voyager HTTP APIs (no browser automation). That usage is against LinkedIn’s terms of service. Use only with an account you control, expect sessions to expire, and do not treat this as a production scraping product.
